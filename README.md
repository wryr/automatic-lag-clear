# automatic-lag-clear
This lag clear addon can help reduce lag on realms/worlds by having options to include max entities check along the timer to kill hostile (or all mobs) and all ground items, even items dropped by those killed mobs.

I have provided 2 versions to suit your type of need for this addon.


How to use:
> - Find the config item in the equipment section of the creative menu or by typing `/give @s rp:lagclearconfig`.
> - Ensure you have OP.
> - Right click the compass while holding it.
> - Configure the settings you want.
> - The lag clear will always run and change to how you've configured it to.

__Both Addons Features:__
> - Doesn't conflict with any other addon.
> - Easy apply & instantly working.
> - Warns 30s/10s before killing items/mobs.
> - Sounds for warning messages (configurable).
> - No back door & no obfuscation, created by ARAS Staff (me).
> - Must have OP to use the Lag Clear Config item.



__Version A (Recommended):__
> - Customizable config __will save__ even if the world/realm is reloaded.
> - Beta API experiments are required.
> - If Minecraft makes major changes in experimental beta script API that makes the addon stop working, you will have to redownload an updated version posted here, or fix it yourself if it isn't reposted here yet, or temporarily use version B.



__Version B:__
> - Customizable config can be changed but __won't be saved__ when the world/realm is reloaded.
> - However, editing the index.js config section will save in the world/realm the addon is applied to.
> - Beta API experiments are NOT required.
> - The addon will always work even if Minecraft makes major changes in experimental beta script API.



Simply download which version (A or B info above) title addon you want and apply it!
